RESEARCH #2 — ADAPTIVE TEMPORAL COMPUTATION IN SPIKING NEURAL NETWORKS

1. WORKING TITLE

Learning When to Stop: Adaptive Temporal Computation for Efficient Spiking Neural Networks

Catatan:
- Judul masih sementara.
- Judul final ditentukan setelah novelty dan hasil eksperimen jelas.


2. RESEARCH MOTIVATION

Conventional SNN inference commonly uses a fixed number of timesteps for every input.

Hal ini dapat menyebabkan computation yang tidak diperlukan untuk input yang sebenarnya sudah dapat menghasilkan prediksi yang cukup baik dengan timestep lebih sedikit.

Research ini ingin mengetahui apakah SNN dapat belajar menentukan sendiri berapa banyak temporal computation yang diperlukan oleh setiap input.


3. CORE RESEARCH PROBLEM

Pertanyaan utama:

Can a Spiking Neural Network learn to dynamically determine how much temporal computation an input requires?

Formulasi awal:

T(x) <= T_max

Keterangan:
- x = input
- T(x) = jumlah timestep yang digunakan untuk input x
- T_max = jumlah timestep maksimum


4. PRIMARY RESEARCH QUESTION

RQ1:

Can an SNN learn to dynamically allocate temporal computation according to the information requirements of individual inputs?


5. SECONDARY RESEARCH QUESTIONS

RQ2:
Does the learned computation allocation correlate with input difficulty?

RQ3:
Can adaptive temporal computation reduce average computational cost while maintaining comparable task performance?

RQ4:
What is the trade-off between computational budget and task performance?


6. CORE CONCEPT

  ->
Output


Adaptive SNN:

  ->
Output

Expected behavior:

D(x) increases
    =>

7. INITIAL MATHEMATICAL IDEA

The model should dynamically determine:

T(x) <= T_max

Potential halting probability:

p_t = sigmoid(W_h h_t + b_h)

where:
- h_t = hidden state at timestep t
- p_t = probability of halting at timestep t

Potential halting rule:

T(x) = min { t : p_t > tau }

Catatan:
- Formula ini masih berupa initial idea.
- Metode halting final belum ditentukan.
- Threshold tau belum ditentukan.


8. MAIN NOVELTY — HYPOTHESIS

Potential novelty:

A learned temporal halting mechanism that allows an SNN to dynamically determine the amount of computation required for each input.

Catatan penting:
- Ini BELUM boleh dianggap sebagai proven contribution.
- Novelty harus diverifikasi melalui literature review.
- Novelty baru dapat diklaim setelah eksperimen dan perbandingan dengan metode sebelumnya.


9. WHAT THIS RESEARCH IS NOT

Research ini tidak bertujuan untuk:

- Sekadar membuat early-exit dengan threshold hardcoded.
- Sekadar menunjukkan bahwa SNN lebih cepat.
- Menjadikan Delta BPTT sebagai novelty utama.
- Langsung menggabungkan SNN + LLM + ARC + memory + multimodal.
- Membuat klaim bahwa SNN melakukan human-like reasoning.

14. DIFFICULTY

Konsep difficulty sangat penting dalam research ini.

Pertanyaan:

Apakah model benar-benar menggunakan lebih banyak computation untuk input yang lebih sulit?

Expected relationship:

Difficulty increases
    =>
Required temporal computation increases


Dua pendekatan awal:

A. Controlled difficulty
- Difficulty dibuat/dikontrol melalui dataset.
- Contoh: difficulty level 1, 2, 3, 4, 5.

B. Learned/implicit difficulty
- Difficulty tidak diberikan kepada model.
- Model menentukan kapan harus berhenti berdasarkan state/confidence.
- Setelah eksperimen, dianalisis apakah timestep yang dipilih berkorelasi dengan difficulty.

Hipotesis awal:
Pendekatan B lebih menarik sebagai mekanisme utama.
Pendekatan A dapat digunakan sebagai controlled experiment.
